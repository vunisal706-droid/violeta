# Iguales Quest — La Aventura de la Igualdad

Videojuego educativo coeducativo de plataformas con preguntas curriculares para 2.º y 3.er ciclo de Educación Primaria. Aplicación web progresiva (PWA), gratuita, sin registro, sin publicidad y sin recogida de datos.

La protagonista, Violeta, recorre seis mundos temáticos derrotando a los «Prohibidores» (los estereotipos de género) y liberando a seis mujeres pioneras: Margarita Salas, Clara Campoamor, Gloria Fuertes, Lili Álvarez, Hipatia de Alejandría y María Zambrano.

## Contenido

- `iguales-quest.html` — aplicación completa (un solo archivo).
- `manifest.json`, `sw.js` — configuración PWA (instalable y con funcionamiento sin conexión).
- `icons/` — iconos de la aplicación.
- `videos/` — vídeos de agradecimiento de cada pionera.
- `docs/` — memoria pedagógica con las seis situaciones de aprendizaje (Word).
- `LICENSE` — licencia del código (GNU GPL v3).
- `LICENSE-CONTENIDOS.txt` — licencia de los contenidos (CC BY-SA 4.0).

## Puesta en marcha

La aplicación es una PWA de archivo único pensada para publicarse en cualquier alojamiento web estático. Basta con subir toda la carpeta manteniendo la estructura y abrir `iguales-quest.html`. El manifiesto y el service worker requieren servirse mediante HTTP/HTTPS (no funcionan abriendo el archivo directamente desde el disco).
